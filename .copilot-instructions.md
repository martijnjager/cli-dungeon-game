# GitHub Copilot Instructions - CLI Dungeon Game

## Project Overview

**CLI Dungeon Game** is a turn-based dungeon exploration game written in PHP. Players navigate through a procedurally generated dungeon, encounter monsters, battle enemies, manage inventory, and collect treasure.

- **Language:** PHP 8.1+
- **Type:** CLI application
- **Architecture:** Service-based with command pattern
- **Testing:** PHPUnit 11.5
- **Namespace:** `CliGame\`

## Key Architectural Patterns

### 1. Command Pattern
- All game commands extend `Command` abstract class
- Located in `src/Command/Actions/`
- Implement `getName()`, `help()`, `execute(array $arguments): CommandResult`
- Have access to `$this->player`, `$this->map`, `$this->container`

### 2. Service Container (Dependency Injection)
- Singleton pattern: `Container::getInstance()`
- Lazy autowiring with reflection
- Bind services: `$container->bind(Interface::class, fn($c) => new Implementation($c->get(Dependency::class)))`
- Retrieve services: `$container->get(Service::class)`

### 3. Enum Usage
- Type-safe enums in `src/Enum/`
- Used for: `Difficulty`, `MapDirection`, `MonsterType`, `RoomType`
- Prefer enums over string/int constants

### 4. Traits for Shared Behavior
- `AttackPower`: Shared attack calculation
- `DamageBasedHealth`: Health management based on damage taken

## Coding Standards

### PHP Standards
- **PHP Version:** 8.1+
- **Namespace:** `CliGame\`
- **PSR-4 Autoloading:** Files in `src/` correspond to `CliGame\` namespace
- **Type Hints:** Always use strict type declarations; all methods must have return types
- **Doc Blocks:** Use PHPDoc for complex types, especially arrays: `/** @var array<string, Command> */`

### Naming Conventions
- **Classes:** PascalCase (e.g., `UseItemCommand`, `BattleService`)
- **Methods/Properties:** camelCase (e.g., `getName()`, `$inventory`)
- **Constants:** UPPER_SNAKE_CASE (if used)
- **Commands:** kebab-case (e.g., `use-item`, `help`)

### Code Style
- Private properties and methods (prefer encapsulation)
- Single responsibility principle
- Immutable where practical
- Use typed properties: `private string $name`

## Command Development Guidelines

### Creating a New Command
1. Create file in `src/Command/Actions/YourCommand.php`
2. Extend `Command` abstract class
3. Implement required methods:
```php
public function getName(): string          // Command name (kebab-case)
public function execute(array $arguments): CommandResult  // Command logic
public function help(): string             // Help text
```

### CommandResult
- Use `CommandResult::continue($message)` to continue game loop
- Use `CommandResult::quit()` to exit game
- Use `CommandResult::error($message)` for errors

### Command Registration
- Commands are auto-registered via `CommandDiscovery::discoverCommands()`
- No manual registration needed; discovery handles it automatically

## Game Mechanics

### Player
- Has health, experience, inventory, current weapon
- Can equip weapons and use items
- Gains experience through battles

### Monsters
- Types: `Dragon`, `Goblin`, `Troll`
- Have health, attack power, experience rewards
- Generated based on room and difficulty

### Inventory System
- Stores items and weapons
- Items can be retrieved by ID or name
- Items can be used (consumable) or equipped (weapons)

### Battle System
- Turn-based attacks
- Damage calculation based on weapon and attacker's attack power
- Monsters defeated grant experience and gold

### Shop System
- Buy items with gold
- Items can be consumables or weapons
- Inventory management required before purchase

## Common Tasks & Examples

### Access Player Inventory
```php
$item = $this->player->getInventory()->getItemById($itemId);
$this->player->getInventory()->removeItem($item);
$this->player->getInventory()->addItem($newItem);
```

### Check Player Health
```php
if ($this->player->getHealth() <= 0) {
    // Player is dead
}
```

### Get Current Room Info
```php
$room = $this->map->getRoomAt($this->player->getLocation());
$monsters = $room->getMonsters();
```

### Return Command Result
```php
return CommandResult::continue('Success message');
return CommandResult::quit();
return CommandResult::error('Error message');
```

### Retrieve Services
```php
$battleService = $this->container->get(BattleService::class);
$shopService = $this->container->get(ShopService::class);
```
